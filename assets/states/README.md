# State archive images

Add one image per state or union territory here. Use the state's name in lowercase with hyphens:

- `rajasthan.jpg`
- `west-bengal.jpg`
- `himachal-pradesh.jpg`
- `andaman-and-nicobar-islands.jpg`

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`. The app picks up images automatically; no code change is needed.
